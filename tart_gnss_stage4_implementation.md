# 1. Objective

Implement **Stage 4: multi-station 3-D localisation of a GNSS satellite from the measured line-of-sight directions produced by Stage 3**.

Stage 4 combines independent station-level direction estimates

\[
\hat{\mathbf s}_i(t_i)
\]

with known station positions

\[
\mathbf r_i
\]

and their angular uncertainties to infer the satellite 3-D position

\[
\hat{\mathbf x}(t)=(\hat x,\hat y,\hat z)
\]

in an Earth-fixed frame.

Use:

```text
ITRS / ECEF
```

with distances in metres.

The Stage-4 solution must be derived from measured TART directions. TLE predictions may be carried forward for later comparison but must not constrain the fit.

---

# 2. Scientific Principle

For station \(i\),

\[
\mathbf x = \mathbf r_i + \rho_i \mathbf s_i,
\]

where \(ho_i > 0\) is the unknown station-to-satellite range.

Define

\[
P_i = I-\mathbf s_i\mathbf s_i^\mathsf{T}.
\]

The perpendicular displacement of a candidate position from the measured sight line is

\[
\mathbf d_i=P_i(\mathbf x-\mathbf r_i).
\]

The baseline unweighted estimator is

\[
\hat{\mathbf x}
=
\arg\min_{\mathbf x}
\sum_i
\left\|
P_i(\mathbf x-\mathbf r_i)
\right\|^2.
\]

This gives

\[
\left(\sum_iP_i\right)\hat{\mathbf x}
=
\sum_iP_i\mathbf r_i.
\]

Implement this as the baseline solution. The production estimator must incorporate Stage-3 directional covariance.

# 7. Station Coordinate Handling

For every station:

1. load latitude, longitude, altitude from frozen run provenance;
2. convert to ITRS/ECEF metres using WGS84;
3. store the exact coordinate source in the Stage-4 manifest.

Do not hard-code Mauritius, Madagascar, South Africa, or any station.

Default:

```text
--min-stations 3
```

Two-station solutions may exist only as degraded diagnostics.

---

# 8. Time Matching

Station timestamps are independent.

Do not join rows by row number.

For each reference epoch \(t\):

1. choose a reference observation epoch;
2. select nearest valid sample from each station;
3. require

\[
|t_i-t|\le\Delta t_{\max}.
\]

Default:

```text
--time-match-tolerance 0.75
```

seconds.

Store:

```text
reference_time_utc
station_time_utc
station_time_offset_s
```

for every contributing station.

Do not interpolate by default.

# 11. Baseline Triangulation Estimator

Implement:

```python
triangulate_lines(...)
```

Return:

```text
x_ecef_m
y_ecef_m
z_ecef_m
station_ranges_m
line_residuals_m
condition metrics
success
```

Define

\[
A=\sum_iP_i
\]

and

\[
\mathbf b=\sum_iP_i\mathbf r_i.
\]

Solve

\[
A\hat{\mathbf x}=\mathbf b.
\]

Use `numpy.linalg.solve` when appropriate and SVD / `lstsq` fallback when geometry is poorly conditioned.

Do not explicitly invert \(A\) for the point estimate.

# 12. Range Positivity

For each station compute

\[
\rho_i
=
\mathbf s_i^\mathsf T
(\hat{\mathbf x}-\mathbf r_i).
\]

Require:

\[
\rho_i>0.
\]

Flag physically inconsistent solutions:

```text
NEGATIVE_RANGE
```

# 13. Weighted Triangulation

The primary scientific estimator must account for Stage-3 directional covariance.

For station \(i\),

\[
\Sigma_{\theta,i}
=
\begin{bmatrix}
\sigma_{A,i}^2 & \mathrm{cov}_{AE,i}\\
\mathrm{cov}_{AE,i} & \sigma_{E,i}^2
\end{bmatrix}.
\]

Transverse uncertainty scales approximately as

\[
\sigma_\perp\sim\rho_i\sigma_\theta.
\]

Implement an iterative weighted solution:

1. solve unweighted position;
2. estimate ranges;
3. construct transverse covariance;
4. solve weighted least squares;
5. update ranges;
6. iterate to convergence.

A practical objective is

\[
\chi^2(\mathbf x)
=
\sum_i
\mathbf q_i^\mathsf T
\Sigma_{\perp,i}^{-1}
\mathbf q_i.
\]

---

# 14. Tangent Basis

For each sight vector construct orthonormal vectors

\[
\mathbf e_{1,i},\mathbf e_{2,i}
\]

perpendicular to \(\mathbf s_i\).

Then

\[
\mathbf q_i
=
\begin{bmatrix}
\mathbf e_{1,i}^\mathsf T(\mathbf x-\mathbf r_i)\\
\mathbf e_{2,i}^\mathsf T(\mathbf x-\mathbf r_i)
\end{bmatrix}.
\]

The basis must be numerically robust near poles and zenith.

# 24. TLE Handling

Stage 4 is measurement-derived localisation.

TLEs may be copied for reference but must not enter the optimisation.

Prefer the closed-form LOS solution, which needs no TLE initialisation.

TLE residual science belongs to Stage 6.

# 25. Synthetic Validation

Required tests:

### Noise-free exact recovery
Recover the injected 3-D position to numerical precision.

### Angular noise
Recovered position must be statistically consistent with truth.

### Poor geometry
Verify condition number and position uncertainty increase.

### Timestamp offsets
Inject motion and verify timing diagnostics.

### Bad station
Perturb one station strongly and confirm line residuals identify it.

### Two-station case
Confirm degraded diagnostic behaviour.

### Negative-range case
Verify `NEGATIVE_RANGE`.

---
